# Exercícios de Lógica de Programação com JavaScript

Este repositório contém uma coleção de exercícios de lógica de programação resolvidos em JavaScript. Os exercícios são feitos para melhorar minhas habilidades de programação e raciocínio lógico.

## Objetivo

O objetivo deste repositório é praticar e aprimorar o conhecimento em JavaScript, principalmente em lógica de programação e estruturas de controle, através de desafios e exercícios.

## Estrutura

- Cada pasta ou arquivo contém um exercício de programação.
- Os exercícios começam com desafios mais simples e vão aumentando gradualmente em dificuldade.

## Como Contribuir

Sinta-se à vontade para fazer sugestões, abrir *issues* ou enviar *pull requests* com melhorias ou novos exercícios!
